# 读图基础：三视图 · 剖视 · 标注（精简）

按需加载：只在读图拿不准时看这一页；完整读图流程见 `skills/sw-drawing-read/SKILL.md`。

## 一、三视图

- **第一角法**（国内常用）：俯视图在主视图**下方**，左视图在主视图**右方**。
- **第三角法**：俯视图在**上方**，左视图在**左方**。图框里看投影法符号，别凭习惯猜。
- 三条对应关系：**长对正**（主/俯）、**高平齐**（主/左）、**宽相等**（俯/左）。对应关系断了，说明看错了视图或漏了视图。
- **粗实线** = 可见轮廓；**虚线** = 不可见轮廓（孔、背面台阶）；**点划线** = 轴线/对称中心；**双点划线** = 假想投影/运动极限。
- 一个视图里的一条虚线，通常意味着另一个视图里有一个对应的孔或凹腔：先在两视图间找同一条边，再决定它是通孔还是盲孔。
- 只有两个视图时，第三视图优先按"回转体/对称件"补；不对称件必须找到能定前后左右的标注或特征。

## 二、剖视

- **全剖**：用一个剖切平面把件整个切开，适合内部结构为主、外形简单的件。
- **半剖**：一半剖、一半外形，以对称中心线为界；对称件看内部又不想丢外形时用。
- **局部剖**：波浪线围出一小块，只剖要看的那处；波浪线不能穿过孔或轮廓线。
- **阶梯剖 / 旋转剖**：剖切平面转折或绕轴旋转，转折处画粗实线；标注写 `A-A`、`B-B`，在对应视图上标出剖切位置与投射方向。
- **剖面线**：同一零件同方向、同间距；相邻不同零件方向相反或间距不同。剖面线只表示"被切到"，不表示材料。
- **肋板、轮辐、薄壁**：纵剖时通常不画剖面线（按不剖处理），只画外形轮廓。
- 剖视图上**没有虚线**：能看见的画粗实线，看不见的已经被切掉，不要再补虚线。

## 三、标注

- 一个尺寸 = **尺寸界线 + 尺寸线 + 尺寸数字**；数字是唯一可信的量，图形只说明它指着哪条边/哪个孔。
- 常用符号：`Ø` 直径、`R` 半径、`SR` 球半径、`□` 方、`⌒` 弧长、`C` 倒角（C2 = 2×45°）、`M` 公制螺纹、`t` 板厚。
- **尺寸链**：一串数字应能凑成总长。先自己加一遍；加不平就说明其中某个数不是相邻两段之和（可能是基准尺寸或到中心的距离）。
- **基准**：从同一基准出发的尺寸是并联；首尾相接的是串联。串联误差会累积，建模时优先按标注的基准建，不要自己改基准。
- **公差**：`Ø<基本尺寸>H7` 是孔的公差带，`Ø<基本尺寸>h6` 是轴；`±<偏差>` 是 symmetric；未注公差按图框/技术要求。建模取**基本尺寸**，公差写进 assumptions。
- 孔标注 `n×Ø<直径> 通孔` / `n×M<螺纹> 深 <深度>`：个数、直径/螺纹、通/盲、深度四件事都要读出来，缺一项就是没读懂。
- 中心线、对称符号、均布 `EQS`：它们决定阵列的基准与数量，不要只数图上画了几个。

## 四、建模时的落地方式

- 每条标注记成 `{value, kind, tolerance, anchor, view, orientation, datum}`；`anchor` 必须能对上模型里的一个面/轴线/边，说不清指谁的标注不能拿去建模。
- 先算尺寸链和派生量（如孔心高 = 总高 − 半径 − 板厚），派生量标 `derived:true` 并写算式。
- 虚线对应的孔：先判断通/盲，再用 `expect.checks[]` 量"轴线到面"的距离，别只量孔径。
- 三视图对不上时，先怀疑自己看错视图（第一角/第三角），再怀疑图纸。
